# Code of Conduct

## Our standard

We want this project to be a welcoming place for curious, constructive work.
Examples of behavior that helps include:

- treating people with respect and assuming good intent
- giving specific, actionable technical feedback
- welcoming questions and different levels of experience
- owning mistakes and repairing harm

Harassment, threats, sexualized attention, discriminatory language, deliberate
intimidation, doxxing, and sustained personal attacks are not acceptable.

## Scope

This standard applies in repository discussions, reviews, issues, and other
spaces where someone represents the project.

## Enforcement

Maintainers may edit or remove contributions and may temporarily or permanently
restrict participation when behavior violates this standard. Enforcement will
consider context, severity, repetition, and the safety of affected people.

To report conduct privately, use the maintainer contact route linked from the
[djh58 GitHub profile](https://github.com/djh58). If there is an immediate
safety risk or a GitHub Terms of Service violation, also use
[GitHub's abuse-reporting tools](https://support.github.com/contact/report-abuse).
Do not use a public issue to disclose private information about another person.
